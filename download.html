⬇ Unduh Aplikasi (APK)

File APK belum tersedia saat ini. Sementara, pakai versi web di bawah, atau pasang dari browser (Chrome menu titik tiga, lalu Pasang aplikasi). Coba lagi nanti ya.

  1. Ketuk tombol di atas, tunggu unduhan selesai.
  2. Buka file KebunMurojaah.apk dari notifikasi atau folder Download.
  3. Kalau muncul peringatan, ketuk Setelan lalu izinkan pasang dari sumber ini. Peringatan ini wajar karena aplikasi tidak lewat Play Store.
  4. Ketuk Pasang, lalu buka. Izinkan notifikasi supaya pengingat bersuara.

🍎 iPhone / iPad

Di iPhone tidak ada file APK. Pasang langsung dari Safari, hasilnya tampil seperti aplikasi:

  1. Buka halaman Kebun Murojaah di Safari.
  2. Ketuk tombol Bagikan (kotak dengan panah ke atas).
  3. Pilih Tambah ke Layar Utama, lalu Tambah.

Pertanyaan yang sering muncul

Apakah aman dipasang?

Ya. Aplikasi ini hanya membuka Kebun Murojaah dan tidak meminta akses kontak, galeri, atau mikrofon. Android menampilkan peringatan karena aplikasinya tidak dari Play Store.

Apakah datanya ikut pindah dari web?

Data tersimpan terpisah di tiap tempat (browser dan aplikasi). Untuk memindahkan, buka Akun lalu pakai Cadangan: salin di web, tempel di aplikasi.

Perlu unduh ulang kalau ada pembaruan?

Tidak. Isi aplikasi ikut terbarui sendiri setiap kali dibuka dengan internet.

Perlu internet?

Perlu sekali di awal. Setelahnya, halaman yang pernah dibuka tetap bisa dibuka saat sinyal jelek.
